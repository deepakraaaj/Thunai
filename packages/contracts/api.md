# Anchor — API Contract (`contracts/api.md`)

> **FROZEN AFTER 0:45.** Single source of truth for every cross-lane interface.
> Frontend (`apps/web`) consumes; Backend (`apps/api`) implements; Core
> (`packages/core`) produces. Shapes are defined in
> [`types.ts`](./types.ts) — this file documents method, path, semantics, and
> rules. **If a contract is missing or wrong, do NOT improvise — log it in
> `PROPOSALS.md`.**

## Product

**Anchor** — web-only, mobile-first recovery & prevention platform for
substance use disorders. Personas: `individual` (Ravi) and `caregiver`.

## Global rules

- **Base path:** `/api`. **Format:** JSON in, JSON out (`Content-Type: application/json`).
- **Live AI only.** Every AI output is generated by a live call at the moment of
  use — Cerebras primary (`gpt-oss-120b`), automatic failover to Gemini
  (`gemini-flash-lite-latest`) on error/429. Never serve cached/canned AI as live.
- **Transparency metadata (`AiMeta`)** accompanies every AI-generated payload:
  `provider`, `modelId`, `latencyMs`, `contextFields[]`. The only permitted
  offline output is the labeled pre-written safety script (`isOfflineFallback:
  true`) — UI must display exactly `Offline safety script (pre-written)`.
- **Keys are backend-only.** Never returned in any response or exposed to the frontend.
- **Validation:** backend validates every input (Zod) against these shapes.
  User text is sanitized before entering any AI prompt.
- **Consent-gated:** caregiver reads require a server-verified consent link.
- **Errors:** standard `ApiError` envelope with `error.code` + `error.message`.
  Codes: `validation_error` (400), `not_found` (404), `consent_required` (403),
  `provider_unavailable` (503), `internal` (500).

## Endpoints

### 1. `POST /api/scripts/sos`
Generate a live, in-the-moment SOS coping script for an individual in craving/crisis.

- **Request:** `SosRequest` → `{ userId }`
- **Response:** `SosResponse` → `{ script, language, meta, sosEventId }`
- **Core:** assembles persona context (name, substance, stage, trigger,
  motivation, language, time-of-day) → `buildSosPrompt` → provider router.
  Output is in the user's language (Tamil for Ravi), warm/non-clinical, ends
  with one small doable action. Persists a `sos` timeline event → `sosEventId`.

### 2. `POST /api/scripts/caregiver`
Generate a coaching script telling the caregiver what to say/do in response to a
specific SOS moment.

- **Request:** `CaregiverScriptRequest` → `{ sosEventId }`
- **Response:** `CaregiverScriptResponse` → `{ script, language, meta }`
- **Core:** looks up the SOS event + linked individual's profile →
  `buildCaregiverPrompt` → router. Consent link between caregiver and user must
  exist (`403 consent_required` otherwise).

### 3. `POST /api/checkins`
Record a daily check-in from browser speech-to-text; classify mood + risk, run
crisis-safety detection, and return a warm AI reflection.

- **Request:** `CheckinRequest` → `{ userId, transcript }`
- **Response:** `CheckinResponse` → `{ id, mood, riskLevel, aiReflection, escalation?, meta }`
- **Core:** `classifyCheckin` (mood + risk) → `detectCrisisLanguage` (safety
  layer). If crisis language is detected, response includes `escalation` with
  **Tele-MANAS / 14416** and the UI surfaces the helpline prominently.
  `aiReflection` is warm, non-clinical, ends with one small doable action.
  Persists a `checkin` timeline event.

### 4. `POST /api/scripts/slip`
Compassionate, shame-free response to a slip/relapse plus a ready-to-send
WhatsApp reach-out draft.

- **Request:** `SlipRequest` → `{ userId }`
- **Response:** `SlipResponse` → `{ script, whatsappDraft, language, meta, slipEventId }`
- **Core:** `buildSlipPrompt` → router. Never guilt/shame. `whatsappDraft` is
  plain text the user can paste into WhatsApp. Persists a `slip` timeline event.

### 5. `GET /api/timeline/:userId`
Unified recovery timeline.

- **Response:** `TimelineResponse` → `{ userId, events[] }` (newest-first)
- **Events:** `sos | checkin | slip | milestone | prediction`. No AI call —
  reads persisted events only.

### 6. `GET /api/insights/:userId`
Weekly pattern summary + derived risk windows.

- **Response:** `InsightsResponse` → `{ userId, weeklySummary, riskWindows[], meta }`
- **Core:** `deriveRiskWindows(checkins)` computes `riskWindows[]`;
  `buildInsightsPrompt` turns the pattern into a warm weekly summary via router.

### 7. `GET /api/predictions/:userId`
Active pre-crisis nudge if *now* falls inside a derived risk window.

- **Response:** `PredictionResponse` → `{ userId, active, window?, nudge?, meta? }`
- **Core:** `getActivePrediction(checkins, now)`. When `active`, a live nudge is
  generated (`meta` present). When not active, `active: false` and no AI call.

### 8. `POST /api/link`
Create a consent-gated caregiver↔individual link.

- **Request:** `LinkRequest` → `{ caregiverId, userId, consent: true }`
- **Response:** `LinkResponse` → `{ linkId, caregiverId, userId, consent, linkedAt }`
- **Rule:** `consent` must be literally `true` (`400 validation_error` otherwise).
  This link is the sole authorization for endpoint #2 and #9.

### 9. `GET /api/caregiver/dashboard/:caregiverId`
Consent-gated caregiver view of linked individuals.

- **Response:** `CaregiverDashboardResponse` → `{ caregiverId, linkedUsers[] }`
- **Rule:** only users with an active consent link appear. `inRiskWindowNow`
  drives a "check on them" prompt. No AI call (reads persisted state).

### 10. `POST /api/scenario/load`
Seed **INPUT DATA ONLY** for demo/eval. **Never** injects AI outputs/scripts.

- **Request:** `ScenarioLoadRequest` → `{ reset? }` (defaults `reset: true`)
- **Response:** `ScenarioLoadResponse` → `{ seeded: {...} }`
- **Seeds:** profiles **Ravi** (alcohol, 90 days, trigger work stress,
  motivation daughter Ananya, language Tamil, dailyCost ₹525) and **Meera**
  (opioids, 14 days, trigger loneliness, language English); **3 weeks of
  check-in history with a Friday-night risk pattern**; caregiver profile + a
  consent link. Seed data is exported by `packages/core` (`scenario.ts`).

## Ownership of the data layer

`packages/core` owns domain logic (prompts, router, safety, risk windows) and
exports the scenario seed + pure classifiers. `apps/api` owns persistence
(store), routing, validation, consent enforcement, and calls into core. Types
flow one way: **core/api/web all import `contracts/types.ts`.**
